# Anima batched-CFG experiment

This private opt-in package clone changes only the execution layout of eligible plain-CFG predictions. Public `anima/`, scored R14 packages, installed packages and Runtime policy are unchanged. `PROVENANCE.json` records the fresh repository base and hashes of the frozen R14 source copied here. Package identity is `cozy-experiment-anima-batched-cfg`; any immutable candidate must additionally record resolved dependency versions and source/artifact hashes.

With first-block-cache disabled, the exact Diffusers `ClassifierFreeGuidance` consumes the same prepared conditional/unconditional states. The experimental denoiser concatenates their embeddings and repeats latents/timesteps along the batch dimension, performs one transformer forward, splits predictions back into their original order, and delegates the guidance equation to the original guider. Scheduler, prompt, seed, noise generation, steps, dimensions, dtype, guidance interval, guidance rescale and original-formulation option remain unchanged. Outside the interval (or guidance1), the existing single-prediction path runs.

The package chooses its layout policy before pipeline execution and deterministically repeats that choice on retry. First-block-cache>0 selects the original sequential block tree: separate cond/uncond cache residuals and threshold decisions are preserved. No OOM/failure fallback changes the layout. Unknown/custom guider classes (including zero-star and skip variants) and incompatible conditioning shapes use the original loop. The request logs its policy; the experimental block logs each actual layout/reason once, including single-prediction intervals and conservative fallbacks.

Source audit of the resolved Diffusers0.40 implementation:

- `modular_pipelines/anima/denoise.py`: stock loop orders guider states, runs the transformer once per state, then calls the guider. This experiment replaces only that denoiser block in the actual retained workflow tree. Progress, before/after blocks, scheduler and pipeline hooks remain in place.
- `guiders/classifier_free_guidance.py` and `guider_utils.py`: plain guider preparation increments a counter and cleanup is empty; guidance mixing/rescale is retained. Other guider classes may install model hooks and are delegated unchanged. We do not generalize this assumption to future/custom guiders.
- `models/transformers/transformer_cosmos.py`: the singleton spatial padding mask is repeated internally by batch size. Concatenating the mask externally would double-repeat it and is incorrect. Latents, timestep and conditioning use the true batch axis.
- This package exposes the text2image workflow, not an added ControlNet/control path. FBC is its explicit transformer mutation; it stays sequential. Runtime's generic managed-forward boundary still sees the real batch2 demand and retains authority over admission/retry. No component/model-specific Runtime policy is introduced.

CPU tests use real Diffusers guider arithmetic and real tensors, with deterministic per-example transformer math. They prove guidance/order/channel mapping, batch sizes, interval edges, rescale/original formulation, unknown guider and incompatible-shape delegation, no retry-dependent fallback, provenance, and installation in the executed modular tree. They do not prove GPU numerical equivalence or performance. Batch shape can change kernel choice, accumulation rounding, activation/scratch demand and therefore image bytes. A qualification must compare same-input decoded outputs and perceptual/numerical differences as well as end-to-end time, measured calls and memory movement. Do not silently promote this clone or substitute it into the R14 comparison.

The measured motivation is separate: the unchanged Comfy3GiB Anima diagnostic observed30 `apply_model` calls at batch2 for30steps, while Cozy R14 recorded60 transformer calls and149.486GB invoke movement at3GiB. Halving forwards is a hypothesis for improving that cost, not a prediction of2x speed or a guarantee that batch2 fits the same residency plan.
